# Quiz Game 🎮

A quiz game website where users can choose different categories and play quizzes based on their interests. The website contains multiple pages and different types of questions. Each category has its own quiz section with different questions for users to answer. The project was created to make learning more fun and interactive while also improving website development skills.

The website is designed with multiple pages connected together so users can easily move between categories and explore different sections of the website. Every page has its own purpose and helps make the website feel more complete and realistic.

---

# Features

* Choose different categories to play
* Different questions in every category
* Multiple connected pages
* Simple and easy-to-use design
* Interactive quiz experience
* Navigation between pages
* Educational and fun gameplay
